# ZCode 插件开发文档

这套文档来自一次完整的 ZCode 插件（[agent-model-router](https://github.com/ops120/ops120-zcode-plugins)）开发、发布、排错全过程，所有坑都是真实踩过的。

## 按你的情况选文档

| 我想**从零做一个自己的插件**并发布出去 | [01 - 从零发布你的第一个 ZCode 插件](01-从零发布你的第一个ZCode插件.md)（30~60 分钟跟做教程） |
| 我**遇到了问题**：装不上、不触发、收不到更新、报错 | [02 - ZCode 插件开发实战指南](02-ZCode插件开发实战指南.md)（开头的症状速查表直接查） |
| 我想**少踩坑、做得更可靠**、举一反三到其他 Agent 平台 | [03 - Agent 插件开发通用方法论](03-Agent插件开发通用方法论.md)（真实生效点、防护闭环、两层验证……） |

## 三篇的关系

```
01 入门教程 —— 带你完整走一遍：写 → 装 → 测 → 发布 → 更新
      │
      ├── 02 速查手册 —— 平台机制 + 按症状查问题（ZCode 专属）
      │
      └── 03 通用方法论 —— 坑背后的工程原则（跨平台通用）
```

- **01 → 02**：教程跑不通时，按症状去 02 查
- **02 → 03**：速查表告诉你"怎么修"，03 告诉你"为什么会这样、下次怎么避免"
- **03 → 02**：方法论落地到 ZCode 的具体路径和操作，都链回 02
